# 🗼 도쿄 여행 지도

귀여운 파스텔 도쿄 지도에서 **내 위치 확인 · 장소 검색 · 길찾기(소요 시간/환승 안내) · Day별 일정표**를 만들 수 있는 웹앱이에요.

## 기능
- 🐰 **내 위치**: 실시간으로 내 위치 표시, 📍 버튼으로 따라가기
- 🔍 **검색**: 도쿄 중심으로 장소 자동완성 검색 (지도 위 가게/역 아이콘을 눌러도 선택돼요)
- 🚇 **길찾기**: 출발/도착을 고르면 대중교통·도보·자동차 소요 시간, 거리, 요금, 노선·환승·역 수·출발/도착 시각을 알려줘요. 출발 시간 지정 가능, 대체 경로 비교
- 📒 **일정표**: Day 1, Day 2 … 로 장소를 저장하고 시간·메모 추가, 순서 변경, **하루 동선 보기**로 장소 사이 이동 시간과 총 이동 시간 확인
- 💾 일정은 브라우저에 자동 저장되고, JSON으로 내보내기/불러오기 가능

## Google Maps API 키 준비
1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고 결제 계정을 연결해요.
2. **API 및 서비스 → 라이브러리**에서 아래 API를 사용 설정해요.
   - Maps JavaScript API
   - Places API (New)
   - Routes API
   - (선택) Geocoding API — 지도 빈 곳을 눌렀을 때 주소 표시
3. **사용자 인증 정보 → API 키 만들기**
4. 키 제한: *애플리케이션 제한* → **웹사이트(HTTP 리퍼러)** 에 앱 주소(예: `https://<아이디>.github.io/*`, `http://localhost:*/*`)를 추가하세요.

> 예전에 만든 키라서 기존(레거시) Places API / Directions API만 켜져 있어도 자동으로 그쪽으로 전환돼서 동작해요.

## 실행
- 처음 열면 API 키를 물어봐요. 입력하면 이 브라우저에만 저장돼요 (📒 일정표 탭 아래 **🔑 API 키 변경**으로 바꿀 수 있어요).
- 또는 `config.js`의 `apiKey`에 직접 넣어도 돼요. (공개 저장소라면 리퍼러 제한 필수!)
- 위치 기능은 **HTTPS**(또는 localhost)에서만 동작해요.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# → http://localhost:8000/tokyo/
```

GitHub Pages를 켜면 `https://<아이디>.github.io/flowersforyou/tokyo/` 에서 바로 쓸 수 있어요.
